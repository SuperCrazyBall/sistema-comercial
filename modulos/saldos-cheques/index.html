Ajuda rápida
  1. Selecione a planilha do dia no campo Arquivo Excel.
  2. Clique em Gerar análise para ler a aba Fluxo.
  3. Use o campo Período para ver todos os registros ou escolher uma data inicial e final.
  4. Alterne entre Resumo e Detalhamento para conferir os totais ou indicadores do recorte.
  5. Em Formas de pagamento, use Resumo para ver grupos gerais ou Detalhado para ver filiais/linhas, sempre separados em recebimentos e pagamentos.
  6. Passe o mouse nos gráficos para ver os valores e use Salvar imagem ou Imprimir quando precisar.

A planilha é processada no navegador; somente a análise calculada é salva como última análise no Firebase.
